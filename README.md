# PowerShow

macOS 메뉴 바에서 현재 시스템의 총 전력 사용량을 실시간으로 확인할 수 있는
간단한 전력 모니터 앱입니다.

> 이 앱이 표시하는 값은 하드웨어 전력 센서의 직접 측정값이 아니라 CPU와 GPU
> 사용량을 바탕으로 계산한 추정값입니다. 실제 소비 전력과 차이가 있을 수 있습니다.

## 주요 기능

- 메뉴 바에 추정 전력 사용량을 `W` 단위로 표시
- 순간적인 변동을 줄이기 위해 최근 측정값을 평균내어 표시
- 설정 창에서 로그인 시 자동 실행 여부 설정
- 설정 창을 닫아도 메뉴 바에서 계속 실행

## 요구 사항

- Apple Silicon Mac 권장

전력 특성은 Mac 모델과 macOS 버전에 따라 다르게 동작할 수 있습니다.

## 사용 방법

1. 메뉴 바의 PowerShow 전력 표시를 확인합니다.
2. 메뉴를 열고 **설정 창 열기**를 선택합니다.
3. **맥북 켤 때 자동으로 실행하기**를 켜거나 끕니다.
4. 앱을 종료하려면 메뉴에서 **종료 (Quit)** 를 선택합니다.

## 설치 방법

1. `PowerShow-1.0.dmg` 파일을 엽니다.
2. PowerShow 앱을 `Applications` 폴더로 드래그합니다.
3. `Applications` 폴더에서 PowerShow 앱을 실행합니다.

처음 실행할 때 macOS에서 앱의 실행을 확인하는 메시지가 표시되면 **열기**를 선택합니다.
